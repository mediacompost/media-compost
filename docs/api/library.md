# Opening a library

`open_library()` is the way in. It returns a [`Library`][media_compost.library.Library],
which is a context manager, and everything else on this page hangs off it.

See [Python API](../python-api.md) for the guide — what to reach for first, and
why the API is shaped this way. This page is the exhaustive list.
